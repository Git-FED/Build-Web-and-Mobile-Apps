THE FULL WORKFLOW

From URL to
release candidate.

A practical breakdown of what happens at each stage and what you receive at the end.

B / 06
01

Describe the app shell

Enter the public site URL, human-facing app name, and reverse-domain bundle ID. The builder normalizes the URL and derives a sensible identifier when possible.

appId · appName · server.url
02

Select the surfaces

Choose only the platforms you intend to ship. Mobile targets map to Capacitor; Windows, macOS, and Linux map to Electron; Web / PWA produces installable metadata.

android · ios · windows · macos · linux · web
03

Check the live shell

The device monitor loads the URL in a sandboxed preview so you can catch a bad address or unexpected responsive behavior before exporting.

preview.status · preview.domain
04

Export the handoff

Download the Capacitor config, Electron config, and PWA manifest separately. The generated command tells you the next local build step.

npm install && npx cap sync android ios

FAQ / FIELD NOTES

The questions that
come up next.

A quick reference for the decisions behind the console.

F / 06
Does this rebuild my website?

No. It wraps the live HTTPS URL. Your site remains the content source and can continue to deploy independently.

Do I need every platform selected?

No. Select only what you need. The generated commands and output files respond to your chosen targets.

What does the PWA output do?

It creates installable metadata including display mode, orientation, start URL, theme color, and background color.

Where should Cloudflare deploy from?

For a plain HTML repo, deploy the repository root with npx wrangler deploy --assets=. and leave the build command blank.
